# Sodrófás Játék

## Link
- https://gy-szilard.github.io/sodrofas-jatek/

## A játékról:
- Ez egy egyszerű játék, aminek a lényege, hogy leüsd az NPC-ket, anélkül, hogy meghalnál.

## Mozgás
- W, A, S, D

## Ütés
- Space *vagy*
- Egér bal kattintás

## Vissza a spawn-ra:
- Q billentyű

## Játék teljes újra kezdése
- R billentyű

## Halál utáni újrakezdés
- Enter

## Sebzés és gyógyulás
- A játék előrehaladtával az enemy egyre többet sebez (max 15-öt / ütés) és a szív egyre többet gyógyít (max 40-et / szív).

## Telefonról is játszható?
 - Igen, játszható, ugyanúgy böngészőben meg kell nyitni
 - Csak generálásbeli különbségek vannak (kisebb labirintus és kevesebb enemy)
